# OOP as It Should Be in C#

Welcome to this repository! This repository represents the summary of my study and mastery of Object-Oriented Programming (OOP) concepts in C#, building upon my previous practical experience and background in OOP (which was actively practiced and applied previously in C++ during Level 10). This course focuses on understanding the subtle nuances and properly applying these concepts in a C# environment.

## Concepts & Topics Mastered in This Course:
- Seamless transition and understanding of how to implement Object-Oriented Programming within the C# language environment.
- Designing classes and objects using correct, robust architectural practices.
- Utilizing access modifiers to control encapsulation and protect data.
- Applying properties correctly instead of exposing fields directly.
- Managing object lifecycles using constructors and destructors.
- Understanding static members, static classes, and their real-world use cases.
- Proper application of the four core pillars of Object-Oriented Programming:
  * Encapsulation
  * Abstraction
  * Inheritance
  * Polymorphism
- Mastering advanced C# concepts:
  * Abstract classes and interfaces
  * Method overriding vs. method hiding
  * Upcasting and downcasting
  * Composition vs. inheritance
  * Sealed classes and methods
  * Partial classes and methods
- Understanding the architecture of reusable class libraries.
- Writing clean, extensible, and maintainable software code.

## Repository Approach & Methodology:
- Given a strong, pre-existing practical foundation in OOP (from C++ applications in earlier levels), the primary focus here was intensely and deeply placed on conceptual understanding and optimal execution in C#.
- Emphasizing correct software design decisions while avoiding rigid or fragile code.

## Outcomes & Takeaways:
- Thinking naturally in terms of objects when writing and structuring code in C#.
- Complete control over code complexity, managing it cleanly and professionally.
