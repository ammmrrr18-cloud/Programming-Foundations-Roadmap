# C# Essentials & Windows Forms Applications (Level 14)

Welcome to the repository for Level 14: C# and Windows Forms! You can access the projects and application code for this level directly via the following link:
[Windows Forms Projects on GitHub](https://github.com/ammmrrr18-cloud/Programming-Foundations-Roadmap/tree/main/C%23%20-%20Level%201/Windows_Forms)

This project covers core and intermediate concepts in C#, .NET architecture, and Desktop Application Development using Windows Forms.

---

## 📋 Course Overview & Learned Topics

### 1. Library, Framework, and Platform Concepts
- Library vs Framework vs Platform: Understanding fundamental differences and architectural roles.

### 2. .NET & .NET Framework Architecture
- .NET Fundamentals: Differences between .NET Core, .NET Framework, and modern .NET implementations.
- Compilation Process: How C# code compiles into Intermediate Language (IL).
- CLR Internals:
  - CLR Architecture & Core Components.
  - Common Type System (CTS) & Common Language Specification (CLS).
  - Garbage Collection (GC) & Memory Management.
  - Just-In-Time (JIT) Compilation.
  - Assemblies, Metadata, and Manifests.
  - Managed Code vs Unmanaged Code.
  - Framework Class Library (FCL).

### 3. C# Syntax & Language Basics
- Introduction: C# features and core syntax compared to C++.
- Input & Output Operations: Using Console.WriteLine() and Console.Write(), Formatted Strings, Escape Characters, and reading user input.
- Data Types & Helpers:
  - Working with DateTime, TimeSpan, calculating date differences, and string-to-date conversion.
  - String Operations, Interpolation, Data Type Casting (Implicit, Explicit, Enum Casting), and Conversion Methods.

### 4. Operators & Control Flow
- Operators: Assignment, Arithmetic, Relational, Logical, Unary, Ternary, and Bitwise/Shift operators.
- Control Structures: Conditional Statements (if, switch), Ternary Operator (? :), and Loops (for, while, do-while, break, continue).

### 5. Data Structures & Functions
- Arrays: Array bounds, declaration, initialization, element access, 2D arrays, and iteration using foreach.
- LINQ with Arrays: Using System.Linq for Min, Max, Count, Sum, and Average operations.
- Methods & Math Operations: Method parameters, default values, return values, Named Arguments, and Method Overloading.
- Error Handling: Basic Exception Handling techniques.

## 🖥️ Windows Forms Application Development & Practical Projects

### 🛠️ Learned UI Controls
- Basic Controls: Labels, LinkLabels, TextBoxes (Focus, MaxLength, Password Mask, WordWrap, MultiLine), Buttons, CheckBoxes, RadioButtons, GroupBoxes.
- Data Entry & Selection: MaskedTextBox, ComboBox, CheckedListBox, NumericUpDown, TrackBar, ProgressBar.
- Date & Time Controls: DateTimePicker, MonthCalendar, Timer.
- System & Dialogs: NotifyIcon, ErrorProvider, ColorDialog, FontDialog, SaveFileDialog, OpenFileDialog, FolderBrowserDialog.
- Containers & Layouts: Panel, TabControl, TreeView, ListView, ImageList, MDI Containers, MenuStrip, Context Menu.
- Graphics (GDI+): Drawing Lines, Ellipses, and Rectangles.
