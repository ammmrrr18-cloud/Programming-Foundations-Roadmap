# نظام إدارة طلبات مطعم البيتزا

مرحباً بك في مستودع مشروع نظام طلبات البيتزا، وهو عبارة عن أحد **الأنظمة الوظيفية** المتكاملة والمصممة لتسهيل وتنسيق عمليات اختيار وطلب الوجبات بشكل رقمي ذكي وسلس. تم بناء هذا النظام بالاعتماد على واجهات المستخدم الرسومية لتقديم تجربة مستخدم تفاعلية واحترافية.

---

## 🛠️ الميزات الأساسية للنظام

* **الصفحة الرئيسية التفاعلية:** واجهة دخول منسقة تتيح الانتقال السريع بين أقسام النظام المختلفة.
* **قائمة الطعام الذكية:** تتيح اختيار أحجام البيتزا المختلفة، وأنواع العجائن بدقة.
* **شاشة الإضافات المخصصة:** إمكانية تحديد المكونات الإضافية وحساب تكاليفها بشكل تلقائي وفوري.
* **قائمة الأسعار المحدثة:** شاشة مخصصة لعرض الأسعار بوضوح لضمان الشفافية مع العميل.
* **ملخص وتأكيد الطلبات:** شاشة مراجعة نهائية تقوم بحساب الإجمالي بدقة وتأمين الطلب لمنع التعديل العشوائي بعد التأكيد، مع ميزة إعادة تعيين الطلبات لبدء عملية جديدة فوراً.
* **صفحة التعريف بالمطعم:** واجهة مميزة تعرض رؤية المطعم وقصته للعملاء بأسلوب بصري راقٍ.

---

## 📁 هيكلية الشاشات والملفات داخل النظام

بناءً على التصميم البرمجي للمشروع، ينقسم النظام إلى مجموعة من الواجهات المترابطة:

* **MainPage:** الشاشة الرئيسية وبوابة الدخول للنظام.
* **MenuePage:** شاشة القائمة واختيار الحجم ونوع العجينة وتحديد مكان تناول الطعام.
* **frmToppings:** شاشة التحكم في الإضافات وحساب الأسعار الإجمالية.
* **frmOrderSummary:** شاشة الفاتورة النهائية وتأكيد وتصفير الطلبات.
* **frmPriceList:** شاشة عرض قائمة الأسعار التفصيلية.
* **AboutUsPage:** شاشة التعريف بقصة المطعم ورسالته.
