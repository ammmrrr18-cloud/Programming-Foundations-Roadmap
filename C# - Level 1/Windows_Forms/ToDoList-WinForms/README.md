# مشروع قائمة المهام (To Do List)

## نبذة عن المشروع

هو مشروع بسيط تم تطويره باستخدام لغة C# وتقنية Windows Forms، ويهدف إلى إدارة المهام اليومية بطريقة منظمة من خلال تقسيمها إلى تصنيفات (Categories) وإضافة المهام (Tasks) داخل كل تصنيف.

تم تنفيذ المشروع بغرض التدريب على استخدام عناصر Windows Forms المختلفة وتنظيم الكود وتقسيمه إلى دوال صغيرة لإعادة الاستخدام.

---

## مميزات المشروع

- إضافة تصنيفات جديدة (Categories).
- إضافة مهام داخل كل تصنيف.
- تعديل اسم أي تصنيف أو مهمة.
- حذف تصنيف أو مهمة.
- حذف جميع المهام مع رسالة تأكيد.
- تحديد جميع المهام كمكتملة (Mark All Done).
- إلغاء تحديد جميع المهام (Uncheck All).
- حساب نسبة إنجاز المهام تلقائياً.
- عرض عدد المهام الكلي وعدد المهام المكتملة.
- شريط تقدم (Progress Bar) يعرض نسبة الإنجاز.
- إشعارات باستخدام NotifyIcon عند تنفيذ العمليات المختلفة.
- التحقق من صحة الإدخال قبل تنفيذ أي عملية.
- رسائل تنبيه وإرشاد للمستخدم عند حدوث أي خطأ.

---

## العناصر المستخدمة

- TreeView
- ProgressBar
- NotifyIcon
- MessageBox
- Label
- TextBox
- Button

---

## المهارات التي تم تطبيقها

- التعامل مع TreeView وإدارة العقد (Nodes).
- استخدام الدوال (Methods) لتقليل تكرار الكود.
- التحقق من صحة البيانات (Validation).
- استخدام DialogResult لتأكيد العمليات.
- حساب نسبة الإنجاز.
- استخدام NotifyIcon لإظهار إشعارات النظام.
- تنظيم الكود وتحسين قابليته للقراءة.

---

## طريقة التشغيل

1. افتح المشروع باستخدام Visual Studio.
2. قم بتشغيل البرنامج.
3. أضف تصنيفاً جديداً.
4. اختر التصنيف.
5. أضف المهام الخاصة به.
6. قم بتحديد المهام عند الانتهاء منها لمتابعة نسبة الإنجاز.
