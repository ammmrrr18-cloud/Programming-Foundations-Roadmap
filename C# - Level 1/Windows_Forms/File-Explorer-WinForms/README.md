# 🌳 WinForms TreeView File Explorer

## 📌 Overview

This project is a simple **C# Windows Forms** application created for practicing the **TreeView** control.

It simulates a basic File Explorer structure and focuses on understanding how to work with TreeView nodes, child nodes, images, checkboxes, and the most commonly used TreeView properties and methods.

---

## ✨ Features

- Display folders using **TreeView**
- Display icons using **ImageList**
- Support CheckBoxes
- Expand All folders
- Collapse All folders
- Expand checked folders
- Collapse checked folders
- Check All folders
- Uncheck All folders
- Display the selected folder name
- Display the parent folder name
- Copy checked folders to the output area
- Clear the output area
- Validation messages using MessageBox

The goal of this project is to gain practical experience with the **TreeView** control by building a small File Explorer-style application and applying the most important features provided by this control.

# 🌳 مستكشف الملفات باستخدام TreeView

## 📌 نظرة عامة

هذا المشروع هو تطبيق بسيط باستخدام **C# Windows Forms**، وتم تنفيذه بغرض التدريب العملى على كنترول **TreeView**.

يقوم المشروع بمحاكاة مستكشف ملفات بسيط، مع التركيز على فهم كيفية التعامل مع العقد (Nodes)، والتفرعات، والصور، وخاصية الـ CheckBoxes، بالإضافة إلى أهم الخصائص والدوال الخاصة بالـ TreeView.

---

- عرض المجلدات باستخدام TreeView

- توسيع جميع المجلدات (Expand All)
- طى جميع المجلدات (Collapse All)
- توسيع المجلدات المحددة (Expand Checked)
- طى المجلدات المحددة (Collapse Checked)
- تحديد جميع العناصر (Check All)
- إلغاء تحديد جميع العناصر (Uncheck All)
- عرض اسم المجلد المحدد
- عرض اسم المجلد الأب
- نسخ العناصر المحددة إلى منطقة الإخراج
- مسح منطقة الإخراج
- رسائل تحقق باستخدام MessageBox
