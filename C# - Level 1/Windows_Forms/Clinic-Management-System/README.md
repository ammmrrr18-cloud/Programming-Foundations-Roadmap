# 🏥 Clinic Management System

## 📖 نبذة عن المشروع

نظام بسيط لإدارة عيادة أسنان تم تطويره باستخدام **C# Windows Forms** بهدف التدريب على تصميم واجهات المستخدم، والتعامل مع عناصر Windows Forms المختلفة، وإنشاء نظام حجز مواعيد بسيط مع التحقق من صحة البيانات.

---

# 🎯 فكرة المشروع

يقوم المستخدم بإدخال بيانات المريض ثم حجز موعد داخل العيادة من خلال اختيار الطبيب والخدمات المطلوبة وتاريخ الحجز، مع التأكد من صحة جميع البيانات قبل إتمام عملية الحجز.

---

# 🛠️ التقنيات المستخدمة

- C#
- Windows Forms (.NET Framework)
- Visual Studio

## 👤 صفحة بيانات المريض (Patient Information)

يقوم المستخدم بإدخال:

- الاسم بالكامل.
- رقم الهاتف.
- الرقم القومي.
- العنوان.
- الجنس.
- تاريخ الميلاد.
- ملاحظات إضافية (اختيارية).

### التحقق من صحة البيانات

يقوم النظام بالتحقق من:

- عدم ترك الحقول المطلوبة فارغة.
- اختيار الجنس.
- أن يكون تاريخ الميلاد قبل تاريخ اليوم.
- تلوين الحقول غير الصحيحة باللون الأحمر.
- نقل المؤشر تلقائياً إلى أول حقل يحتوى على خطأ.
- عرض رسالة توضح سبب الخطأ للمستخدم.

## 📅 صفحة حجز الموعد (Appointment)

يقوم المستخدم بـ:

- اختيار الطبيب.
- عرض الخدمات الخاصة بالطبيب المختار تلقائياً.
- اختيار خدمة واحدة أو أكثر.
- اختيار تاريخ الحجز.
- مشاهدة الوقت الحالي الذي يتم تحديثه بشكل تلقائي.
- تفعيل أو إلغاء استقبال إشعارات الحجز.
- زيارة الموقع الإلكتروني للعيادة من خلال رابط مباشر.

### عند حفظ الحجز

يقوم النظام بـ:

- التحقق من اختيار الطبيب.
- التحقق من اختيار خدمة واحدة على الأقل.
- عرض إشعار (Notification) من خلال **NotifyIcon** عند نجاح الحجز إذا كانت الإشعارات مفعلة.
- فتح الموقع الإلكتروني للعيادة عند الضغط على رابط الموقع.
