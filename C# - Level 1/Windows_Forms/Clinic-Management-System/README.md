
# 🏥 نظام إدارة عيادة (Clinic Management System)

## 📖 نبذة عن المشروع

هذا المشروع هو تطبيق سطح مكتب (Windows Forms) تم تطويره باستخدام لغة C# بهدف التدريب على استخدام عناصر واجهة المستخدم (Windows Forms Controls) وتطبيق أساسيات البرمجة مثل التحقق من صحة البيانات (Validation)، التعامل مع الأحداث (Events)، وتنظيم الكود باستخدام الدوال (Methods).

---

# 🎯 أهداف المشروع

- التدريب على تصميم واجهات Windows Forms.
- تطبيق أساليب التحقق من صحة البيانات (Validation).
- تعلم التعامل مع الأحداث (Events).
- تنظيم الكود وتقسيمه إلى دوال صغيرة قابلة لإعادة الاستخدام.
- التدريب على التنقل بين النوافذ (Forms).

---

# 🛠️ التقنيات المستخدمة

- C#
- Windows Forms (.NET Framework)
- Visual Studio

---

# 🖥️ النوافذ الموجودة بالمشروع

### 1- الصفحة الرئيسية (Home)

تحتوى على:

- بدء حجز موعد جديد.
- الخروج من البرنامج.

---

### 2- صفحة بيانات المريض (Patient Information)

يقوم المستخدم بإدخال:

- الاسم بالكامل.
- رقم الهاتف.
- الرقم القومي.
- العنوان.
- الجنس.
- تاريخ الميلاد.

مع التحقق من صحة جميع البيانات قبل الانتقال للصفحة التالية.

---

### 3- صفحة حجز الموعد (Appointment)

تحتوى على:

- اختيار الطبيب.
- عرض الخدمات الخاصة بكل طبيب.
- اختيار الخدمات المطلوبة.
- اختيار تاريخ الحجز.
- عرض الوقت الحالي.
- تفعيل أو إلغاء الإشعارات.
- رابط لموقع العيادة.
- حفظ الحجز.

# ✅ ما تم تطبيقه داخل المشروع

- التنقل بين النوافذ.
- التحقق من صحة البيانات (Validation).
- التحقق من الحقول الفارغة.
- التحقق من اختيار الجنس.
- التحقق من تاريخ الميلاد.
- التحقق من اختيار الطبيب.
- التحقق من اختيار خدمة واحدة على الأقل.
- تغيير لون العناصر عند وجود خطأ.
- عرض رسائل تنبيه للمستخدم.
- تحديث الوقت الحالي باستخدام Timer.
- تغيير الخدمات تلقائياً حسب الطبيب المختار.
- عرض إشعار باستخدام NotifyIcon.
- فتح موقع العيادة باستخدام LinkLabel.
